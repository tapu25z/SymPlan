\begin{abstract}
Executable symbolic programming helps language models overcome calculation errors in mathematical reasoning. While frontier models succeed by jointly interpreting, planning, and generating code in a single unconstrained pass, compact small language models (SLMs, $\le 8\text{B}$) under 4-bit quantization collapse under this monolithic burden. Limited capacity induces cognitive overload, causing semantic goal drift, omitted domain boundaries, and repair regressions. To bridge this gap without parameter scaling, we propose \textbf{SymPlan}, an inspectable neurosymbolic framework for resource-constrained reasoning. SymPlan establishes an immutable \textit{target anchor} that locks the queried unknown and its formal output signature prior to code generation, stabilizing SymPy synthesis and preventing regressive overwrites during debugging. Across six open-weight quantized models (3B--8B) on MATH-500, SymPlan outperforms monolithic SymCode by $+3.60\%$ to $+5.20\%$ (averaging $+4.20\%$) and Chain-of-Thought by $+12.64\%$, raising execution success to $89.90\%$ without fine-tuning.

\keywords{Neurosymbolic AI \and Small Language Models \and Mathematical Reasoning \and SymPy Code Generation \and Algorithmic Planning.}
\end{abstract}

\section{Introduction}

Chain-of-Thought (CoT) prompting~\cite{wei2022cot} and structured search~\cite{wang2023selfconsistency,zhou2023leasttomost,wang2023plan} have advanced language model reasoning, yet autoregressive generation still produces arithmetic errors and unfaithful derivations~\cite{lyu2023faithful,lightman2024verify}. Program-aided approaches delegate computation to external interpreters: PAL~\cite{gao2023pal} and PoT~\cite{chen2022pot} execute numerical Python, MathCoder~\cite{wang2024mathcoder} and ToRA~\cite{gou2024tora} blend tool calls with rationales, and SymCode~\cite{nezhad2025symcode} uses SymPy~\cite{meurer2017sympy} for exact algebra.

However, execution cannot guarantee mathematical correctness if formalization fails to represent the problem faithfully~\cite{lyu2023faithful,pan2023logiclm}. Most methods synthesize interpretation, planning, and code in a single unconstrained prompt~\cite{gao2023pal,nezhad2025symcode}. While frontier models manage this joint task, compact models ($\le 8\text{B}$) under 4-bit quantization~\cite{dettmers2023qlora} degrade severely on MATH-500~\cite{lightman2024verify,hendrycks2021math} due to four failure patterns:
(1)~\textit{semantic misformulation}, solving distorted equations;
(2)~\textit{target-anchor drift}, diverging from the queried variable or type signature;
(3)~\textit{domain boundary omission}, admitting extraneous roots without bound checks; and
(4)~\textit{silent repair regression}, where self-debugging replaces valid solutions with incorrect ones.

To resolve these failures, we introduce \textbf{SymPlan}, an inspectable neurosymbolic framework for compact models. SymPlan decouples reasoning into three stages: a bounded \textit{Fused Target-Anchoring Phase} ($\le 256$ tokens) fixing the queried variable, formal output signature, and algorithmic roadmap; a \textit{Target-Anchored Code Generator} producing domain-constrained SymPy code; and a \textit{Targeted Debugging Loop} pairing AST diagnostics with an \textit{Anti-Regression Selection} mechanism to preserve valid solutions.

Our contributions are:
(1)~characterizing formulation, target drift, and repair failures across six compact models on MATH-500;
(2)~proposing SymPlan to decouple target anchoring, SymPy synthesis, and anti-regression repair; and
(3)~demonstrating consistent gains over SymCode ($+3.60\%$ to $+5.20\%$) and CoT ($+12.64\%$), raising ESR to $89.90\%$ without fine-tuning.

\section{Related Work}

\textbf{Program-Aided Reasoning.} PAL~\cite{gao2023pal}, PoT~\cite{chen2022pot}, MathCoder~\cite{wang2024mathcoder}, and ToRA~\cite{gou2024tora} offload computation to Python, while SymCode~\cite{nezhad2025symcode} uses SymPy~\cite{meurer2017sympy} for exact algebra. However, monolithic generation overburdens compact models: misinterpreted equations or omitted domain boundaries yield mathematically invalid code.

\textbf{Formalization and Code Repair.} Faithful CoT~\cite{lyu2023faithful} separates reasoning from execution, Logic-LM~\cite{pan2023logiclm} refines symbolic forms, and Self-Debugging~\cite{chen2024selfdebug} patches scripts iteratively. On compact models, unanchored repair causes code cycling and silent regressions. SymPlan grounds repair through an immutable target anchor and anti-regression tracking.

\textbf{Planning in SLMs.} Structured prompting, including Self-consistency~\cite{wang2023selfconsistency}, Least-to-Most~\cite{zhou2023leasttomost}, and Plan-and-Solve~\cite{wang2023plan}, enhances reasoning in compact models. SymPlan extends these concepts by establishing explicit target anchors and verifiable execution steps tailored for quantized models.

\section{Method}
\label{sec:method}

\subsection{Framework Formulation}

Given a problem $q$, monolithic symbolic approaches~\cite{nezhad2025symcode} generate and execute code in one unconstrained pass: $C_{\text{base}} \sim \mathcal{M}(\cdot \mid q)$, $\hat{y} = \operatorname{Exec}(C_{\text{base}})$. On compact models, this joint generation causes semantic drift and execution crashes. SymPlan structures problem solving into three target-anchored phases:
\begin{align}
\mathcal{T} = (\tau, \Sigma, \mathcal{P}) &= \operatorname{FusedPlan}_{\mathcal{M}}(q), \label{eq:fused_plan} \\
C^{(0)} = \operatorname{CodeGen}_{\mathcal{M}}(q, \mathcal{T}), &\quad \mathcal{H} = \operatorname{ExecuteAndRepair}_{\mathcal{M}}(C^{(0)}, q, \mathcal{T}), \label{eq:codegen_repair} \\
\hat{y} &= \operatorname{SelectBest}(\mathcal{H}, \Sigma), \label{eq:select}
\end{align}
where $\tau$ denotes the queried unknown, $\Sigma$ is the formal output signature, $\mathcal{P}$ represents the computational plan, and $\mathcal{H}$ records execution history. Like an anchor man stabilizing team structure, establishing $\mathcal{T}$ prior to code generation anchors mathematical intent throughout execution and debugging.

\subsection{Fused Target Anchoring and Algorithmic Planning}

Multi-turn prompting pipelines often double autoregressive latency and induce context drift in compact models. SymPlan extracts the target anchor and plan $\mathcal{T} = (\tau, \Sigma, \mathcal{P})$ in a single bounded pass ($\le 256$ tokens):
(1)~\textbf{Target Specification ($\tau$):} the formal quantity queried (e.g., positive real roots);
(2)~\textbf{Formal Output Signature ($\Sigma$):} a discrete type $\Sigma \in \{\text{numeric}, \text{text}, \text{tuple}, \text{set}, \text{symbolic}\}$, where cardinality queries map to $\Sigma = \text{numeric}$; and
(3)~\textbf{Computational Plan ($\mathcal{P}$):} ordered symbolic steps $(p_1, \ldots, p_m)$ specifying symbols, equations, transformations, and domain boundary checks.

\subsection{Target-Anchored SymPy Code Generation}

Given $(\tau, \Sigma, \mathcal{P})$, generator $\operatorname{CodeGen}_{\mathcal{M}}$ produces self-contained SymPy code enforcing four invariants:
(1)~\textit{Exact Arithmetic:} rationals use \texttt{sp.Rational(p, q)}; floats are avoided unless requested.
(2)~\textit{Domain Filtering:} roots from \texttt{sp.solve} are checked against domain bounds ($x \in \mathbb{R}^+$, non-zero denominators).
(3)~\textit{Simplification:} expressions are canonicalized via \texttt{sp.together()} or \texttt{sp.cancel()}.
(4)~\textit{Signature Conformance:} the script prints a single boxed \LaTeX{} answer strictly conforming to $\Sigma$.

\begin{lstlisting}[style=promptstyle,language=Python]
import sympy as sp; x = sp.Symbol('x', real=True); eq = sp.Eq(sp.sqrt(x), x - 2)
cands = sp.solve((x - 2)**2 - x, x); valid = [s for s in cands if s >= 2 and eq.lhs.subs(x, s) == eq.rhs.subs(x, s)]
print(r"\boxed{%s}" % sp.latex(valid[0]))
\end{lstlisting}

\subsection{Targeted Debugging with Anti-Regression Selection}

Execution proceeds in an isolated sandbox ($\tau = 15$s, retry limit $K=2$) with three safeguards:
\textbf{AST Diagnostics:} Tracebacks $e^{(i)}$ are paired with static AST checks (\texttt{lint\_sympy\_code}) and candidate verification $v^{(i)}$.
\textbf{Anti-Cycling Repair:} If $C^{(i)} \equiv C^{(i-1)}$, prompt constraints force an alternative implementation strategy.
\textbf{Anti-Regression Ranking:} Attempts are recorded in $\mathcal{H} = \{r_0, \ldots, r_k\}$ and scored via $\operatorname{Rank}(r) = \langle \mathbb{I}_{\text{exec}}(r), \mathbb{I}_{\text{valid}}(r), \mathbb{I}_{\text{verif}}(r), -\operatorname{attempt}(r) \rangle$, prioritizing verified earlier runs over speculative later mutations. The optimal output is $r^* = \arg\max_{r \in \mathcal{H}} \operatorname{Rank}(r)$, with multi-tier regex fallback for malformed outputs.

\section{Experiments and Results}
\label{sec:experiments}

\textbf{Setup.} We evaluate on the MATH-500 benchmark~\cite{lightman2024verify,hendrycks2021math} (7 subjects, 5 difficulty levels) across six open-weight models: Qwen2.5-3B-Instruct, Qwen3-4B, Qwen2.5-7B-Instruct, Qwen2.5-Coder-7B-Instruct, Llama-3.1-8B-Instruct, and Qwen3-8B. All models run under 4-bit NF4 quantization~\cite{dettmers2023qlora} with greedy decoding. For fair comparison, both SymCode~\cite{nezhad2025symcode} and SymPlan share an identical debugging budget of up to $K=2$ retries with interpreter feedback. Baselines also include Direct generation and CoT~\cite{wei2022cot}, measuring Accuracy (\%~EM) and Execution Success Rate (ESR).

\textbf{Main Results.} Table~\ref{tab:mainresults} reports results across the evaluated models. SymPlan consistently outperforms monolithic SymCode by $+3.60\%$ to $+5.20\%$ (averaging $+4.20\%$) and CoT by $+12.64\%$ (reaching $+23.20\%$ on Coder-7B). Under the shared $K=2$ retry budget, monolithic repair frequently induces silent regressions where retries overwrite correct intermediate outputs; SymPlan counters this by achieving higher initial accuracy ($C^{(0)}$ pass@1) and preserving valid candidates via anti-regression ranking. Average ESR rises from $83.83\%$ to $89.90\%$ ($+6.07\%$), reducing runtime failures by $37.5\%$. In inference cost, SymPlan generates only $22.6\%$ more tokens than SymCode ($392.9$ vs. $320.6$ tokens/problem), remaining substantially below CoT ($423.7$ tokens), confirming that gains stem from structured anchoring rather than repetitive trial-and-error.

\textbf{Stratified Analysis and Ablation.} Table~\ref{tab:stratified} shows that gains concentrate in intermediate problems (Level 3: $+11.43\%$ on Coder-7B) and subjects with strict algebraic constraints: \textit{Algebra} ($+9.67\%$), \textit{Counting \& Prob.} ($+13.15\%$), and \textit{Number Theory} ($+9.68\%$). As detailed in Table~\ref{tab:ablation}, component ablations confirm that target anchoring ($+1.90\%$ avg) and algorithmic planning ($+1.40\%$ avg) each improve accuracy independently, while combining both with anti-regression ranking achieves the highest accuracy ($54.57\%$, $+4.20\%$ over baseline) and an ESR of $89.90\%$.

\textbf{Error Diagnostics and Mechanistic Insights.} As shown in Table~\ref{tab:error_breakdown}, SymPlan eliminates 126 errors across 3,000 runs ($-8.5\%$ relative drop). Safe SymPy templates lower crashes by $37.5\%$, and formal output signatures cut format mismatches by $23.5\%$. In multi-condition algebra, target anchoring registers domain bounds and evaluation points beforehand, preventing constraint omission and enabling exact symbolic reconstruction. Conversely, semantic misformulations remain flat ($974 \to 969$, $-0.5\%$), showing that neurosymbolic scaffolding resolves execution-interface failures while relying on base-model knowledge for non-constructive problem formulation.

\section{Conclusion}

We presented SymPlan, an inspectable neurosymbolic framework for mathematical reasoning in compact models. By decoupling problem solving into fused target anchoring, specification-guided SymPy synthesis, and targeted debugging with anti-regression ranking, SymPlan resolves boundary omission and repair regressions. Across six quantized models (3B--8B) on MATH-500, SymPlan outperforms monolithic SymCode by $+3.60\%$ to $+5.20\%$ and CoT by $+12.64\%$, raising execution success to $89.90\%$ without fine-tuning. Future work will extend SymPlan to interactive theorem proving and geometric diagrams.
